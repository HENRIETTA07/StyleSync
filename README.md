# StyleSync — AI Wardrobe Assistant

StyleSync is an Android application being developed to help users organise their wardrobe and receive personalised outfit recommendations based on their clothing, preferences and occasions.

This is a group final-year project for the Diploma in Information Technology at Politeknik Balik Pulau.

## Project Objectives

* Make daily outfit selection easier.
* Help users discover and use more items in their wardrobe.
* Recommend suitable clothing and accessories for different occasions.

## Planned Features

* **Digital Wardrobe:** Add and manage clothing, footwear and accessories.
* **Clothing Recognition:** Automatically identify and categorise uploaded items.
* **AI Outfit Recommendations:** Suggest combinations based on wardrobe items and user preferences.
* **Weather Integration:** Consider weather conditions when recommending outfits.
* **Event Planning:** Connect outfit planning with Google Calendar events.
* **Saved Outfits:** Save favourite combinations and review outfit history.
* **Admin System:** Support centralised management of application data.

## Development Tools

* Android Studio for Android application development.
* Firebase for backend services.
* OpenAI API for planned AI functionality.

## Project Status

**In development.** Features are being implemented, connected and tested. The feature list describes the intended project scope and does not mean that every feature is complete.
